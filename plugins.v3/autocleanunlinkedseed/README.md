# Emby智能入库删种 · MoviePilot V3

版本 2.0.0，支持 MoviePilot 3.1.0 至 V4 之前。使用 V3 SDK 的下载器服务、事件和通知接口，保留原 Webhook、定时扫描、标签过滤、目录映射和手动扫描功能。

在插件市场使用源 `https://github.com/Agonie0v0/MoviePilot-Plugins` 安装或更新。保持原插件 ID 和配置目录，已有设置无需重新填写。

扫描已完成下载的任务；排除标签优先于包含标签。检查映射后的源文件硬链接数，只有满足断链条件才请求下载器删除任务及源文件。下载器明确确认删除后才计入成功通知。停用时阻止新扫描并等待当前扫描退出，避免重载后遗留线程继续删种。

该插件的用途是**硬链接入库后的源清理**：硬链接数不能证明云盘上传成功，不适合把“115等待上传的视频源”当作已经入库的断链文件。请使用包含标签将扫描范围限定为硬链接入库任务，并用排除标签排除云盘等待任务。

验证使用模拟 qBittorrent 下载器，没有删除任何真实下载任务；实际环境仍需确认目录映射、标签及硬链接工作流。详细验证范围见 [V3 兼容性报告](../../docs/v3-compatibility.md)。
