# 115秒传等待 · MoviePilot V3

版本 1.2.0（测试版），支持 MoviePilot **V3 系列**内置 115，不再限制具体小版本。本地视频的复制和移动整理未命中秒传时，在原整理记录中显示失败，由后台队列重试；远端文件确认后，交给 V3 原生持久整理计划完成整理，将**同一条记录**更新为成功。

## 安装和升级

在插件源添加 `https://github.com/Agonie0v0/MoviePilot-Plugins`，刷新市场并安装或更新“115秒传等待”。V3 会加载 `plugins.v3/p115instantwait`，请勿使用 V2 的本地安装脚本。

升级 V3 前请先在 V2 完成或取消等待任务，保留插件数据目录和配置。V2 遗留任务会保留为暂停，只允许取消；需要在 V3 中重新发起整理。升级不会直接改写旧宿主数据库，也不会自动发送遗留任务的文件内容。

## 配置

| 设置 | 含义 | 默认值 |
| --- | --- | --- |
| 启用秒传等待 | 接管本地视频到内置 115 的复制或移动整理 | 关闭 |
| 任务状态通知 | 首次等待、达到上限和异常时提交 MP 渠道通知并写站内消息 | 开启 |
| 最多重试 | 不含首次尝试，0 表示首次失败即执行上限策略 | 3 次 |
| 最长等待 | 本轮等待时限；0 表示不限时 | 24 小时 |
| 达到上限后 | 选择“手动处理”或“强制上传”；次数、时间任意一项达到即执行 | 手动处理 |
| 重试间隔 | 秒，逗号分隔，超过列表后使用最后一项；允许 30～86400 秒 | 60,180,600,1800 |
| 扩展名 | 逗号分隔的本地视频扩展名 | 常见视频格式 |

配置页支持搜索多选任务，批量暂停、继续等待、强制上传或取消。“继续等待”重置本轮次数和时限；“强制上传”先试秒传，未命中便上传正文。普通上传使用独立线程，期间其他整理和自动秒传队列仍可运行。异常或源文件变化会暂停，不会因为上限策略自动绕过校验。

任务详情和日志显示原整理记录 ID、任务 ID、状态、累计尝试、本轮自动尝试和下次重试时间。MP 全局通知设置仍需开启相应渠道及“整理”/“手动处理”消息类型。

记录页显示入队时间，以及完成、结束或最近更新时间（按 MP 所在时区，精确到秒）。展开“最新结果”可查看失败原因；成功时按实际传输结果显示“强制上传成功”或“触发秒传成功”。强制上传操作仍可能命中秒传，此时显示“触发秒传成功”。缺少传输确认标记的旧记录显示“传输方式未记录”，不推测结果。

## 记录统计与预览

顶部统计 queue.db 内全部保留记录，完成项区分秒传、上传与传输方式未记录。下方只加载按入队时间选出的最近 50 条；状态筛选与页面批量操作仅作用于这 50 条。V3 的「等待回写」计入执行与上传，不计为成功，在配置查询中可见但不可选中操作。

## 全库搜索与分页操作

在配置页展开「批量任务操作 · 全库查询」或「清理已结束记录」，后者选择「选择指定记录」。

1. 输入文件名、源路径、任务 ID 或 MP 整理记录编号（支持 `#123`），可选择状态，再点击「搜索」或按回车。查询覆盖数据库全部对应记录，不受监控页最近 50 条限制。
2. 使用「上一页 / 下一页」浏览，每页最多 50 条，显示匹配总数和页码。任务操作区查询全部未结束可管理任务，清理区查询全部已结束任务；输入框最多 200 字，`%`、`_` 等字符按普通文字匹配。
3. 在「选择本页任务 / 选择本页已结束记录」中勾选，再选择操作并勾选保存时执行，最后点击 MP 配置窗口的「保存」。不跨页保留选择；每次搜索、翻页都会清空本区选择和执行勾选，查询失败也不会保留旧选择。

搜索和翻页是只读请求，不需要保存配置，也不会暂停后台任务。执行操作仍经原来的保存流程，停止调度后重新检查任务状态，保护未完成任务及批次恢复依赖。查询使用 MP 前端提供的认证 API；若前端过旧缺少 `MoviePilotAPI`，界面会提示更新，不绕过认证。搜索条件、页码及结果只存于当前配置窗口，关闭重开从第一页开始；保存后插件会移除这些临时数据。

## 历史清理

### 完整记录保存方案

- **现已保存**：插件数据目录（`get_data_path()`）下的 `queue.db` 长期保存全部任务和恢复检查点，200/50 都只是读取上限，不会自动裁剪数据库。MP 整理历史保留原整理记录和结果，可在 MP 整理历史界面查询；插件特有的重试与上传检查点以 `queue.db` 为准。
- **统计口径**：顶部按全库当前状态实时汇总，是“全部保留记录”，不是每次重试加一的累计事件计数。手动删除历史后数量相应减少；过去已删除的插件记录无法自动补回。升级会一次性回填传输方式并建索引，保留原记录 ID、时间和 payload；后续页面只解码 50 条详情，统计扫描较小的覆盖索引，仍随记录数量线性增长。
- **备份建议**：连同 MP 数据目录定期备份插件数据目录。在线备份应使用 SQLite backup API 生成一致性副本；直接复制文件时先停止 MoviePilot，完整保存 `queue.db` 及仍存在的 `queue.db-wal`、`queue.db-shm`，不要在运行中只复制主数据库。备份放在其他存储位置，恢复时先停服务并保留当前数据副本。本版没有新增自动备份任务。
- **后续按需导出规划（本版未实现）**：分页查询已实现；后续增加 CSV 导出与时间过滤，导出分批读取；字段包括任务 ID、MP 历史 ID、源/目标路径、状态、秒传或上传方式、尝试次数、入队/更新时间及结果，不导出上传会话和原始 payload。导出不会删除数据库记录。
- **大数据量归档规划（本版未实现）**：确有磁盘压力时再按月归档已结束任务，保留可查询索引；未完成任务和同批次恢复依赖不能搬走。归档须先校验备份成功再删除源记录，届时顶部统计同时计入在线与归档记录，避免归档造成数量下降。本版不自动清理或归档。


配置页展开「清理已结束记录」，保存时执行一次，随后自动取消勾选。

- 可多选已结束记录，或按成功/失败/已取消状态与保留天数清理。条件清理覆盖全部历史，不受每页 50 条展示限制。默认保留最近 30 天，填 0 清理全部匹配记录，按记录结束时间计算。
- 未完成任务不能删除；同批次仍有未完成任务时，恢复所需成功记录会跳过。
- 只删除插件队列记录，保留 MoviePilot 整理历史、本地源文件和网盘文件。插件关闭时也可清理。此操作不可撤销，重新打开配置可查看结果。

## V3 的完成流程

1. V3 冻结并持久化原整理计划；插件返回等待结果，由宿主写原失败记录。
2. 独立线程计算哈希、等待秒传，或按操作进入普通分片上传。源文件保留，文件直接写入正式目录和正式文件名，不创建暂存或备份目录。CMS 媒体创建事件对应正式路径，实际事件投递由 115 与 CMS 决定。
3. 远端文件校验通过后，显示“等待 V3 回写”。插件只登记原失败任务的重试意图；宿主恢复调度器取得任务租约后重放原计划，核对已落地的正式文件，并执行移动模式的源删除；不会再移动或重命名远端视频。
4. 完成前再次确认精确目标文件 ID 和文件大小；可取得 SHA1 时同时核对。宿主更新原记录并发送成功事件，插件标记完成。

“等待 V3 回写”期间不可重复手动操作，避免与宿主完成步骤竞争。原生恢复调度器有调度延迟，此状态不会直接显示成功。若 V3 将外部步骤隔离为人工复核，需要先在宿主整理队列核对和处理，再恢复插件任务。

覆盖判断使用 V3 原生冻结整理计划，支持总是覆盖、大覆盖小、从不覆盖、仅保留最新版本及覆盖检查事件。按 MP 允许的范围删除旧文件后直接上传；不允许时沿用 MP 的拒绝结果。不创建备份目录。同一正式路径只允许一个未结束插件任务写入。取消任务保留本地源文件和已上传的正式文件，需人工核对。

覆盖沿用 MP 的先删除旧文件再写入新文件顺序；上传失败或秒传未命中时，旧文件可能已经删除，本地源文件仍保留。不存在旧版本自动回滚。实际删除前核对文件 ID，删除进度持久化；旧文件被其他操作替换时暂停，避免删错对象。

## 升级与异常恢复

- 旧版未结束暂存任务会暂停，仅允许取消。核对旧网盘文件后，取消旧队列并从 MP 重新整理；旧上传会话不会改写到正式路径。升级不会删除既有 `.mp115-staging`、`.mp115-backups` 及其中的文件，需人工核对处理。
- 初始化请求前持久化写入意图。响应丢失时先核对正式路径；没有已确认文件 ID 时，要求匹配 SHA1 或同一分片上传的 pick_code，再校验大小。证据缺失、冲突或结果不确定时停止重复上传。
- 秒传明确未命中可继续等待；已确认上传但正式文件尚不可见时只等待元数据。普通上传继续同一分片会话，不新建另一份文件。

## 支持边界

- 单视频文件、本地到内置 `u115`，原生 `copy` / `move`；不支持蓝光原盘目录、替换整个旧目录、外部存储接管和缺失持久任务身份的同步调用。
- 未匹配的字幕、NFO、图片等继续走 MP 原生整理；它们可能先于视频完成。批次刮削等视频完成或取消后释放。
- V3 自身拥有媒体识别、计划、执行步骤、任务租约和整理历史。插件不直接操作宿主 ORM 或会话。
- **不再校验 MoviePilot 版本号**：1.2.0 起移除版本区间硬校验，改由装载时逐项探测所需整理接口（方法是否存在、执行合同签名是否匹配），缺失或变化时停止接管并提示具体原因。
- 已完成隔离测试，尚未在实际 V3 服务器和真实 115 账号上验证授权、上传和通知投递。首次升级建议用一部可恢复的本地测试视频确认完整流程。

验证依据、命令与限制见 [兼容性报告](../../docs/v3-compatibility.md)。
