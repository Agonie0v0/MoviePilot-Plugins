# 阡陌居自动签到插件 (QmjSign)

本插件为 **MoviePilot (MP)** 专用的阡陌居论坛 (`www.1000qm.vip`) 每日自动签到插件，源自于 QD 签到模板实现，提供自动化每日签到、威望红包领取、账号密码自动登录续期 Cookie 等功能。

---

## 🌟 核心亮点与增强特性

- 🔑 **支持账号密码自动登录更新 Cookie**
  - 无需再频繁打开浏览器开发者工具抓取更新 Cookie！
  - 配置论坛用户名和密码后，若检测到 Cookie 失效或初次运行未填 Cookie，插件将自动调用移动安全接口重新登录，换取最新 Session Cookie，并**自动回写持久化到 MoviePilot 插件配置中**。
- 🛡️ **支持 Discuz! 安全提问**
  - 完美适配开启了“安全提问”（如母亲名字、爷爷名字等）的论坛账号。
- ⚡ **毫秒级 Cookie 校验 & 精准容错**
  - 优化 Cookie 快速检测机制，避免因网络响应延迟而误判失效。
  - 改用轻量 API 快速检测登录状态，耗时仅 ~0.2 秒。
  - **精准区分网络异常与凭证过期**：网络超时或波动走常规重试流程，不再误报“Cookie 已过期”；只有凭证真正失效时才触发自动登录或续期提示。
- 🌐 **网络代理 (Proxy) 与超时自定义**
  - 支持配置 HTTP / SOCKS5 代理（如 `http://127.0.0.1:7890`），彻底解决 NAS 或海外 VPS 访问论坛出现的 `ReadTimeout` 或连接失败问题。
  - 可自由调整超时时间（默认 20 秒）。
- 🧧 **每日威望红包与财富总览**
  - 可选自动领取每日威望红包（自动完成任务申请、领取与完成状态追踪）。
  - 自动抓取并汇总财富五项（铜币、威望、贡献、发书数、综合积分）。
- 🎲 **拟真签到机制**
  - 随机心情库（DSU 9大心情） + 丰富随机文案，降低被风控风险。
- 📱 **多渠道通知推送 & 历史面板**
  - 支持 MoviePilot 全渠道（微信、Telegram、Bark、钉钉等）结果推送。
  - 内置优雅的签到历史表格与财富概览卡片。

## 🛠️ 安装方法

### 方式一：直接放入 MoviePilot 插件目录（推荐）

1. 将本项目目录命名为 `qmjsign`（或者把本目录中的 `__init__.py`、`package.json`、`README.md` 等文件拷贝到该文件夹）。
2. 将 `qmjsign` 文件夹放入 MoviePilot 容器的 plugins 映射目录：
   - Docker 映射路径一般为：`/path/to/moviepilot/app/plugins/qmjsign`
3. 重启 MoviePilot 或在插件市场中进行重新加载。

### 方式二：作为个人插件仓库接入

1. 将本项目推送到个人的 GitHub 仓库。
2. 在 MoviePilot 设置 -> 插件 -> 插件源 中添加你的仓库地址。
3. 在插件市场中搜索“阡陌居签到”并点击安装。

## ⚙️ 配置说明

| 配置项 | 说明 | 默认值 / 建议 |
| :--- | :--- | :--- |
| **启用插件** | 开启或关闭插件定时运行 | 关 |
| **开启通知** | 签到成功/失败后是否发送 MoviePilot 系统通知 | 开 |
| **领取每日威望红包** | 签到同时是否自动申请并领取论坛“每日威望红包”任务 | 建议开启 |
| **立即运行一次** | 保存配置后立即执行一次签到并自动关闭该开关 | 调试时开启 |
| **论坛用户名 / 账号** | 阡陌居论坛用户名（用于 Cookie 失效时自动登录更新） | 建议填写 |
| **论坛密码** | 阡陌居论坛密码 | 建议填写 |
| **安全提问** | 论坛账号若设置了安全提问，在此选择对应问题 | 无安全提问 |
| **安全提问答案** | 安全提问的对应答案 | 无则留空 |
| **站点 Cookie** | 阡陌居 Cookie。可留空，配置账号密码后系统会自动登录生成并回填 | 可选 |
| **网络代理** | HTTP/SOCKS5 代理地址，如 `http://127.0.0.1:7890` | 如网络不稳定建议填写 |
| **签到周期** | Cron 定时表达式 | `0 8 * * *` (每天 8:00) |
| **最大重试次数** | 网络波动或请求失败时的自动重试次数 | 3 |
| **重试间隔(秒)** | 每次重试之间的等待秒数 | 30 |
| **网络超时时间(秒)** | 每次 HTTP 请求最大超时时间 | 20 |
| **历史保留天数** | 签到历史记录在本地保存的最大天数 | 30 |
| **清空历史记录** | 开启后点击保存将立即重置并清空签到历史与财富概览（保存后自动复位为关） | 关 |

## ❓ 常见问题排查 (FAQ)

### Q: 为什么有时会出现 “检查Cookie有效性超时” 或 “Read timed out”？
**A:**
由于 1000qm.vip 论坛服务器在高峰时段偶尔响应较慢，若网络波动可能导致连接超时。本插件采用轻量接口进行毫秒级检测，并提供自定义超时配置（默认 20 秒）与网络代理选项；即使遇到底层网络波动超时也会进入智能重试流程，不会误报 Cookie 过期。

### Q: 论坛开启了顶象滑块验证码，插件是如何实现免验证码自动登录的？
**A:**
阡陌居启用了 Discuz! 官方 Mobile 客户端通道。本插件通过专用接口直连安全鉴权管道，直接获取完整的登录凭证（`flo1_2132_auth` 等），避免了网页端滑块验证码的人机对抗与打码成本。

### Q: 我可以只填账号密码，不填 Cookie 吗？
**A:**
可以！本插件支持三种认证模式：
1. **纯账号密码**：初次运行自动登录并生成 Cookie 保存。
2. **账号密码 + 现有 Cookie**：优先使用 Cookie，Cookie 失效无缝自动重新登录更新，最稳定推荐。
3. **纯 Cookie**：适合已有长期有效 Cookie 的用户直接填入使用。
