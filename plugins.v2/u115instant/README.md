# 115 秒传整理

MoviePilot V2 插件。它保护本地到内置 115 存储的“移动”整理：115 初始化上传后若未命中秒传，插件立即结束本次整理，不请求普通 OSS 分片上传，源文件保留并按队列延迟重试。

首版只处理常见视频文件，字幕、NFO、封面等附加文件仍按 MoviePilot 原逻辑处理。建议将对应媒体库整理覆盖模式设为“不覆盖”，避免 MP 在上传前删除旧文件。

插件的失败记录会在 MP 中显示为整理失败，插件详情页会展示运行状态、队列统计、下次重试时间和最近原因。默认在 10 分钟后首次重试，第二次和后续重试间隔可在配置页单独调整，默认分别为 120 分钟和 360 分钟。配置页按运行开关、重试策略和保护边界分组，支持窄屏自适应。停用插件后，MP 会恢复原生普通上传行为。

插件图标使用 PNG 格式，以兼容 MoviePilot V2 图片代理的格式校验。
